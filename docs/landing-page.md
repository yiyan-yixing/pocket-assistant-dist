# 落地页设计文档 · 7 天收意向 ·「口袋助手」

> 定位：**「口袋助手」——让每个手机都拥有自己的 AI：本地为主，云端按需。**
> 日期：2026-08-13 · 主理：@vp-eng · 配套：PRD.md（立项基准）+ scenarios.md（30 场景脑暴）
> 性质：**设计文档**，非成品页；话术文案完整可直接使用。交付 @designer / @dev 据此出页。
> 前置事实标注：**scenarios.md 文件头部写「六大域」，实际只有 5 个域标题**（域一隐私敏感 / 域二离线无网 / 域三省钱高频 / 域四掌控专业 / 域五超级入口探索，30 场景）。因此**落地页意向 buckets 按实际 5 域 + 第 6 个「其他」兜底 = 6 项**，不写「六大域」字样，避免与事实不符。

## 2. 首屏话术（hero）

### 2.1 主标题（固定核心词「口袋助手」）

推荐默认 **C**，A/B 探向时三版各自覆盖（见 §5）：

- **A｜你的手机，住进一个 AI**（口语、有画面感、人人可懂，适合通用随身的 A/B 默认版）
- **B｜每个手机，都该拥有自己的 AI**（主张式、带态度，适合个人生活助手版）
- **C｜口袋助手：隐私、离线、省钱、掌控**（最直给，定位词前置，推荐默认版）

> 规则：**页面标题/`<title>` 与首屏第一行必须出现「口袋助手」**（董事长要求 + 定位一致性）；A/B 版允许在「口袋助手」之外加方向性前缀，不得替换掉定位词。

### 2.2 副标题（四价值锚点·一句话版，四行直排）

> 隐私——数据永不出机，敏感问题放心问。
> 离线——飞行模式、地铁、海外，无网照常答。
> 省钱——日常问答本地零边际成本，无订阅无月费。
> 掌控——引擎模型全透明可换，决定权在你。

### 2.3 CTA 按钮文案

- **主 CTA（首屏唯一）**：「预订早期体验」→ 点击滚到意向表单 / 展开表单，**不是下载**（现在没包）。
- **辅助 CTA（四价值下方）**：「先选一个你最想要的场景」→ 滚到场景卡片区。
- 主 CTA 下方小字（信任降噪）：`7 天意向窗口 · 免费 · 无订阅 · 数据永不出机`。

## 3. 场景示例区（感染力优先）

**从 5 个实际域 + 其他兜底各挑 1 个最有感染力的场景**做卡片；每卡 = 一句话场景 + 一句「为什么本地是刚需」。排序可随 A/B 变化（见 §5），默认顺序如下：

| # | 卡片标题（一句话场景） | 为什么本地是刚需 | 来源 |
|---|---|---|---|
| ① | 隐私 · 私人日记/情感倾诉——「有些话，我不想让任何公司服务器看见」 | 「不想被看」本身就是产品价值，本地 AI 倾听无痕 | 场景 5 |
| ② | 离线 · 飞机上办公——「4 小时断网，邮件、思路、汇报全不卡」 | 飞行模式是唯一可用窗口，云端彻底不可依赖 | 场景 9 |
| ③ | 省钱 · 重度学习者一天 50 次问答——「问得起、问不心疼」 | 量大 = 本地零边际成本优势最大，云按量是长期放血 | 场景 16 |
| ④ | 掌控 · 开发者自建网关——「base_url + BYO key，一套配置切双引擎」 | 引擎透明可定制，不黑盒，云端本地由你定 | 场景 20 |
| ⑤ | 超级入口 · 随身 AI 管家——「日程、提醒、待办、记账，一个本地管家全收」 | 私人生活数据 = 最不该上云的数据 | 场景 24 |
| ⑥ | 其他 · 老人/无障碍语音助手——「爸妈也能用，还不怕被监控、被推销」 | 弱势群体隐私是伦理底线，本地语音不被云端监听 | 场景 30/26 |

> 卡片视觉：每卡 ①图标 emoji ②短标题 ③一句话场景（引号体）④一行「本地刚需理由」。移动端单列堆叠，**首屏第 1 张卡片随 A/B 换位**（探测哪个域最抓人）。

## 4. 意向收集表单

### 4.1 表单结构（字段清单）

| 字段 | 控件 | 必填 | 选项 / 规则 |
|---|---|---|---|
| **① 你最想要哪个场景**（6 域 buckets） | radio 单选 | 必选 | 见 4.2 |
| **② 你在用鸿蒙手机吗** | radio 单选 | 必选 | 见 4.3 |
| ③ 邮箱 / 联系方式 | email | 必填 | 格式校验；**留意向去重 key** |
| ④ 一句话描述你的场景 | textarea | 选填 | ≤ 140 字，喂给种子访谈 |

> 提交按钮：「提交意向，获取早期名额」。提交后页内成功态（不打赏、不跳转外部）。

### 4.2 ① 6 域 buckets（测哪域意愿最强）——**核心字段**

单选（radio，必选），保证「总选次 = 提交数」，**各域占比直接可比**：

1. **隐私敏感**——「问点不想被别人看见的」（日记、合同、病历）
2. **离线无网**——「断网也要能用的」（飞机、地铁、海外、野外）
3. **省钱高频**——「天天用也不心疼的」（日常问答、学习、记账）
4. **掌控专业**——「我自己说了算的」（自建网关、自定义模型、代码）
5. **超级入口探索**——「一个随身 AI 管家」（统一管我生活的 AI）
6. **其他 / 都不是**——「以上都不太是（请在第④栏描述）」

> 统计口径：域强度 = **该域被选次数 / 总提交数**（单选使分母一致）。5 域 + 其他 = 6 项，明确对应「实际 5 域 + 兜底」。单选最优：统计干净、用户负担最小；不采用「限选 2 个」（会引入加权，7 天小样本下反而干扰「哪域最强」判断）。

### 4.3 ② 鸿蒙选项（测 P1 平台决策信号）

单选，四选项，**NEXT 与旧版必须分开**（NEXT = 纯血鸿蒙无 Android 兼容层，旧版可跑 APK，技术含义不同）：

- `HarmonyOS NEXT（纯血鸿蒙）`
- `旧版鸿蒙（HarmonyOS 3/4）`
- `否，用 iOS / Android`
- `计划换鸿蒙`

> 判读见 §8：NEXT + 旧版 + 计划换 三项合计占比，是「鸿蒙需求窗口」成立信号。

## 5. 三类入口方向 A/B 方案（探测 Stage 1 入口方向）

**响应 PRD §2.1**：入口方向不锁死，由落地页意向数据 + 种子反馈探测。三版共用同一页面骨架与表单，仅 **hero 主标题 / 副标题 / 首屏场景卡片排序** 三处不同。

| 维度 | 开发者工作流 `?v=dev` | 个人生活助手 `?v=life` | 通用随身 `?v=general`（默认） |
|---|---|---|---|
| **主标题** | 口袋助手：你的模型网关，装进口袋 | 口袋助手：只属于你的 AI，住进手机 | 口袋助手：你的手机，住进一个 AI |
| **副标题**（前三行换序，第四行不变） | 掌控——引擎模型全透明可换 / 省钱——零边际成本 / 隐私——代码与密钥不出机 / 离线——断网照常 | 隐私——数据永不出机 / 离线——无网照常答 / 省钱——无订阅无月费 / 掌控——决定权在你 | 隐私 / 离线 / 省钱 / 掌控（四行默认序） |
| **首屏场景卡排序** | ④掌控·开发者网关 → ①隐私·代码/合同 → ③省钱·小团队 → ⑤管家 → ②离线 → ⑥其他 | ①隐私·日记倾诉 → ②离线·通勤/地铁 → ③省钱·学习者 → ⑤管家 → ④掌控 → ⑥其他 | ②离线·飞机 → ③省钱·学习者 → ①隐私·日记 → ④掌控 → ⑤管家 → ⑥其他 |
| **CTA 微调** | 「预订开发者优先名额」 | 「预订早期体验」 | 「预订早期体验」 |
| **探向假设** | 开发者愿为「资产+掌控」驻留 | 普通用户愿为「隐私+离线」驻留 | 用户先因「不联网的 AI」驻留，方向后长 |

### 5.1 分流实现

- **URL 参数 + 随机分流**：无 `?v=` 时，首访 JS 从三版中**均匀随机**选一版并 `history.replaceState` 改写 URL（带 `?v=`，保证可分享、可追踪、刷新不变）；`?v=dev|life|general` 直接落到指定版（便于投放渠道锁定文案）。
- **回访固定**：选中版本写入 `localStorage`（key: `landing_v`），同用户回访不换版，避免一人贡献多个版本样本。
- **兜底**：无 JS / 被墙场景下默认渲染 `general` 版（`<noscript>` + 服务端默认 HTML 即为 general）。

### 5.2 统计

每版记录：**展示数（UV）** → 埋点打点带 `v`；**提交数** → 表单成功回调打点带 `v`；**转化率 = 提交数/UV**。三版对比表 + 6 域分布交叉表（`v × 域`），7 天结束出分布结论（判读见 §8）。

## 7. 技术实现说明

### 7.1 形态

**静态单页 HTML，无后端、无构建**。单文件（内联 CSS + 少量 JS），可部署于 GitHub Pages / Vercel / 对象存储 / 微信内直接打开。

### 7.2 表单收集（标注取舍，先落地可手动）

前端 `submit` 拦截 → **双写**：

1. **Formspree 表单服务**（免费版 50 条/月，7 天窗口够用）——`fetch` 提交，成功即算意向。**取舍标注**：Formspree 为境外服务，国内直连可能慢/被墙，且无域名隔离（表单端点带 formspree.io）；若投放以国内为主，**替换为腾讯问卷/金数据 iframe 嵌入**，代价是牺牲自定义样式与 A/B 打点一致性。
2. **localStorage 本地缓存副本**（key: `landing_leads`）——防表单服务挂/被墙时丢数据，手动导出 JSON 兜底。

> MVP 结论：**Formspree + localStorage 双写**，够用、零后端、可导出手动处理。后续接入自有后端（如 Supabase / 自建 API）再平滑迁移。

### 7.3 埋点

- **访问数（UV）**：静态页加一段统计脚本（umami 自托管 / 百度统计 / GA4 均可），带 `v` 参数维度。
- **提交数**：表单成功回调 `+1` 打点（同统计服务），并本地去重（同邮箱只计 1 条）。
- **转化率**：提交数 / UV，三版各自计算。
- 埋点标签：`page=landing&v=dev|life|general&action=view|submit`。

### 7.4 无后端合规最小项（@clo 提醒）

页面页脚明示「邮箱仅用于意向通知，不用于营销」；隐私承诺与 PRD §9 一致（数据不出机 / 云端明示 / Key 仅本机）。表单不采集敏感正文内容，场景描述第④栏为选填且仅用于访谈约聊。

**8-20 能力更新（对齐 App 打磨，落地页话术可引用）**：
- **搜索不跳出 App**：搜网页在 App 内置 WebView 打开，可继续浏览/点链接，不把用户甩给外部浏览器；搜索到的真实结果文本回填给模型，回答有据。
- **云端 key 安全存储**：BYO key 存系统安全存储（iOS Keychain / Android Keystore），不落明文；旧版本明文配置首次打开自动迁移后清除。
- **模型就绪前体验**：首次启动自动加载本地模型，未就绪时发消息给可见中文引导（非静默丢弃），断网/数据不出机承诺在就绪前也可感知。

## 8. 数据统计口径与决策映射

### 8.1 6 域分布 → 哪域最强 → 入口方向建议

| 数据信号（7 天结束） | 判读 | Stage 1 入口方向建议 |
|---|---|---|
| **⑤超级入口·管家** 域占比最高 | 用户要「一个统一管我生活的 AI」 | → **个人生活助手**（对齐 PRD §2.1） |
| **④掌控·开发者网关** 域占比最高 | 开发者要「我的模型我做主」 | → **开发者工作流** |
| **②离线 / ③省钱** 域占比最高 | 用户先为「不联网、不花钱的 AI」驻留 | → **通用随身**（方向随后长，主线不变） |
| **①隐私** 域占比最高 | 隐私是第一购买理由 | → 主推隐私叙事，入口方向取次高域 |
| 三版 A/B 转化分布 | `v=dev/life/general` 哪版转化最高 | 与域分布交叉印证后定入口方向 |

> 交叉印证规则：**域分布定「方向」，A/B 转化分布定「文案」**。二者一致（如管家域高 + life 版转化高）→ 方向明确；不一致 → 以域分布为准（域分布直接回答「最想要哪个场景」）。

### 8.2 鸿蒙选项 → P1 平台决策信号

| 信号 | 判读 | 决策映射 |
|---|---|---|
| NEXT + 旧版 + 计划换 **合计 ≥ 20%** | 鸿蒙需求窗口成立 | P1 鸿蒙适配评估优先级上调（但 MVP 仍只做 iOS+Android，见 PRD §11-1/3） |
| 合计 < 20% | 窗口不成立 | 维持 P1 后置，等 Flutter-OH 成熟 + 双端数据再拍 |

### 8.3 达标 / 不达标 → 后续动作

| 结果 | 动作 |
|---|---|
| **达标**（≥30 条 或 ≥3%） | 付费意愿成立 → 意向名单进入种子访谈 → 启动阶段二 MVP（4 周铁律）→ 6 域 + 鸿蒙数据随 PRD §10 阶段一产出归档 |
| **不达标** | 归因三选一：① 流量不足（投放渠道/分享没跑开）→ 加渠道复测；② 文案错位（A/B 三版都低）→ 重写 hero/场景卡；③ 价格/价值误判 → 种子访谈校准预期。修后 7 天再测 |

### 8.4 数据归档

7 天结束输出 `corp/standup/` 阶段一验证记录 + 意向名单 CSV（邮箱、域、鸿蒙、A/B 版、场景描述）——原始数据进 `knowledge/` 备查，供 P1 排期与入口方向拍板引用。
