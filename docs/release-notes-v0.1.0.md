## 首次使用

1. 安装 APK（允许未知来源）
2. 首次启动自动下载本地模型（约 1.1GB，存放 `/sdcard/Download`，蜂窝默认不自动下载；鸿蒙需先授权「所有文件访问」）
3. 模型就绪后即可离线对话
4. 可选：点顶部徽标切「云端」→ 设置填 baseUrl + API key + 模型名 → 测试 → 保存

## 功能清单（MVP P0 完成）

- 本地离线：Qwen2.5-1.5B GGUF Q4_K_M，数据不出机
- 云端按需：BYO Key 直连任意 OpenAI 兼容网关，引擎一键切换
- 三工具闭环：位置 / 天气 / 搜索（内置 WebView 不跳出 App，结果文本回填）
- 对话历史 SQLite 持久化；日期/时间/星期程序注入；人设统一答复
- 模型就绪前体验（可见引导 + 进度 + 状态区全中文）

## 已知限制

- 意图识别粒度较粗（1.5B 能力边界），触发词兜底/日期注入/人设答复为缓解手段，第二期一次攻克
- iOS 缺 Xcode 后置；HarmonyOS NEXT 适配 P1 后置
- 云端纯对话骨架（不带工具），双引擎统一工具循环第二期
- 模拟器无 GPU 加速生成较慢；真机 Metal/Vulkan 快数倍
